# Internet Archive — Kodi Addon

Kodi addon for browsing and playing Internet Archive content, with Real-Debrid support for resolved playback. Built for Kodi 21 Omega.

Kodi addon (Kodi 21 Omega) — browse, search and play Internet Archive video, with favorites, sorting, pagination and optional Real-Debrid resolving using your own token.

## Install

**From a release:** download the `plugin.video.internetarchive-1.0.0.zip` attached to the latest release on this repo, then in Kodi: Settings → Add-ons → Install from zip file.

**From source:** zip the `plugin.video.internetarchive/` folder so `addon.xml` sits at the zip root, then install the same way.

Every push to `main` re-packages the addon zip and attaches it to a GitHub Release (see Actions), so the release page is always the current install.
